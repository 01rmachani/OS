# Welcome to BrowserOS

Welcome to **BrowserOS** — a fully-featured operating system that runs entirely in your browser. No installation required. Your data lives securely in your browser's local storage.

## What Can You Do?

Explore a rich set of built-in applications:

- 📁 **[[File Manager]]** — Browse and manage your files with a familiar explorer UI
- ✏️ **[[Markdown Editor]]** — Write and edit notes with live preview and `[[wikilink]]` support
- 🕸️ **[[Knowledge Graph]]** — Visualize how your notes connect to each other
- 📖 **[[Wiki]]** — Browse your notes as a beautiful wiki knowledge base
- 💻 **[[Terminal]]** — Run commands on the virtual file system
- 🖥️ **[[Code IDE]]** — Full Monaco Editor (VS Code-like) for coding
- 🤖 **[[AI Terminal]]** — AI-powered coding assistant
- 📡 **[[Live Feed]]** — Watch real-time system events (SSE demo)
- ⚙️ **[[Settings]]** — Customize the OS to your liking

## Quick Tips

- Press **Ctrl+K** to open the Command Palette and search anything
- **Double-click** desktop icons to open apps
- **Right-click** the desktop for options
- Windows can be **dragged, resized, minimized, maximized**, and snapped to screen halves
- Press **Super+1-3** to switch virtual desktops
